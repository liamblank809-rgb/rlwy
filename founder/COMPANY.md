# Founder Company Operating System

Core loop:

Research -> Hypothesis -> Validation -> MVP -> Distribution -> Sales -> Delivery -> Metrics -> Iteration

Every significant initiative should record:
1. Objective
2. Evidence
3. Hypothesis
4. Expected upside
5. Cost/resources
6. Risks
7. Next measurable test
8. Decision and rationale

Core metrics:
- Qualified opportunities
- Customer interviews
- Activation
- Conversion
- Revenue
- Gross margin
- Retention
- Acquisition cost
- Payback period
- Usage
- Delivery time
